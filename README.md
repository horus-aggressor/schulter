# Schulter-Prehab

Schultergesundheit im Winter Arc 2026: Anleitung und Trainings-Tracker.

- **Anleitung:** `index.html` – Einheit A (9 Übungen mit Clips) und Einheit B (5 Ergänzungen), Dosierung, Progression.
- **Tracker:** `tracker.html` – Gewicht und Wiederholungen pro Satz eintragen, Verlauf, Fortschritt, Export als JSON und Markdown.

Der Tracker speichert alles im Browser (localStorage) des jeweiligen Geräts. Es gibt keinen Server.
Auf dem iPhone die Seite über Safari → Teilen → „Zum Home-Bildschirm“ hinzufügen und von dort öffnen,
damit Safari die Daten nicht nach 7 Tagen ohne Nutzung löscht. Regelmäßig unter „Daten“ eine Sicherung exportieren.
